# Code of Conduct

## Our pledge

We pledge to make participation in this project a harassment-free experience for
everyone, regardless of background or identity.

## Our standards

Behaviour that contributes to a positive environment:

- being respectful of differing viewpoints and experiences,
- giving and gracefully accepting constructive feedback,
- focusing on what is best for the project and its learners.

Unacceptable behaviour includes harassment, insulting or derogatory comments,
personal or political attacks, and publishing others' private information.

## Scope

This Code of Conduct applies within all project spaces (issues, pull requests,
discussions) and when an individual is representing the project in public spaces.

## Enforcement

Report unacceptable behaviour by opening an issue or by contacting the
repository owner through their GitHub profile. Maintainers will review and
respond, and may remove, edit, or reject contributions that violate this Code.

This Code of Conduct is adapted from the
[Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
